
# Indian Sales Dashboard

## Project Overview
This project analyzes Indian sales data using Power BI.
It helps understand sales performance, profit, orders, and product trends.

## Tools Used
- Microsoft Excel
- Power BI
- Power Query

## Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Total Quantity

## Dashboard Features
- Monthly Sales Trend
- Sales by State
- Top 5 Products
- Sales Analysis
- Interactive Slicers and Filters

## Files Included
- Indian_Sales_Data.xlsx
- Indian_Sales_Dashboard.pbix
- Dashboard.png

## Project Purpose
To analyze sales data and present useful business insights through an interactive dashboard.
